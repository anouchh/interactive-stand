# Контрольный показ автономного киоска

Из корня репозитория, Python 3 и JDK 17 или новее:

```text
python -m unittest -v
python catalog.py --export example/accepted.tsv
java java/Kiosk.java example/accepted.tsv example/events.tsv S1
```

В case.json хранятся описи, решения по протоколам и регистрация сеанса. Первая команда запускает проверки. Вторая сверяет файлы, проверяет решение и формирует реестр допущенных зон. Третья обрабатывает тот же журнал в Java. Ожидаются motor=2, pump=1 и причины repeat, unknown, time в строках данных 2, 4, 5. Подмена S1 или v1 в строке журнала должна остановить обработку с binding до выдачи сводки. Входные TSV используют табуляцию, одну физическую строку на запись и целые десятичные миллисекунды.
